# SanPlan iOS 26 Companion (AlarmKit)

**Основной сценарий владельца теперь Windows, без личного Mac.** См. [сборку в облаке и установку через Windows](WINDOWS.md). Инструкции для Mac ниже оставлены как альтернативный путь. Подготовка workflow не означает успешной компиляции: её результат и проверку на iPhone нужно получить отдельно.

Нативный iOS-компаньон для сервиса SanPlan на базе технологии Apple **AlarmKit** (iOS 26+). Приложение устанавливает полноценные системные будильники iOS, которые звучат на экране блокировки устройства даже при выключенном экране и закрытом приложении.

---

## 1. Архитектура и безопасность

- **Настоящие системные будильники:** приложение использует официальный API Apple AlarmKit (`AlarmManager.shared`), а **не** имитацию через push-уведомления, VoIP, PushKit или CallKit.
- **Безопасный веб-шлюз (`PlanGateway.swift`):** реализован в проекте: запросы отправляются только на адрес SanPlan, а перенаправления отключены. Приложение не собирает, не запрашивает и не хранит учетные данные пользователей. Авторизация происходит в изолированном контексте `WKWebView`.
- **Изолированный локальный реестр:** приложение сохраняет список зарегистрированных идентификаторов в `UserDefaults` и отменяет **только свои** будильники. Никакие сторонние или личные будильники пользователя никогда не затрагиваются.
- **Детерминированные идентификаторы UUID:** формируются на базе первых 16 байт хэша SHA-256 от комбинации `id задачи + дата/время события + смещение в минутах`. Это исключает дублирование и случайную перезапись будильников при повторных синхронизациях.
- **Политика ограничений (App Policy):**
  - Максимум 5 смещений напоминаний на задачу (в диапазоне от 0 до 40320 минут).
  - Лимит в **50 ближайших хронологических будильников** во всей системе. Это внутреннее правило приложения SanPlan для предотвращения переполнения расписания (не является ограничением Apple).
- **Синхронизация без фоновых процессов:** расписание обновляется при открытии приложения пользователем и нажатии кнопки «Обновить будильники». Ложных фоновых постоянных синхронизаций нет.

## 2. Требования к оборудованию и ПО

- Компьютер **Mac** с установленной средой **Xcode 26** (или новее).
- Смартфон **iPhone** под управлением **iOS 26**.
- Кабель для подключения iPhone к Mac (или настроенное беспроводное подключение).
- Обычный персональный Apple ID (платный аккаунт разработчика за $99/год **не требуется**).

## 3. Пошаговая инструкция по сборке и установке на Mac

### Шаг 1: Открытие проекта в Xcode
1. Склонируйте репозиторий на Mac.
2. Убедитесь, что в директории `native/ios/SanPlan/` присутствует файл `PlanGateway.swift` (поставляется владельцем репозитория).
3. Откройте проект в Xcode:
   ```bash
   open native/ios/SanPlan.xcodeproj
   ```

### Шаг 2: Настройка бесплатного профиля подписи (Personal Team)
1. В левой панели Xcode выберите проект **SanPlan** (самый верхний синий значок).
2. Выберите цель (Target) **SanPlan**, затем перейдите на вкладку **Signing & Capabilities**.
3. В выпадающем списке **Team** выберите вашу личную команду (**Personal Team** с вашим именем / Apple ID).
4. В строке **Bundle Identifier** измените идентификатор на уникальный, например:
   `com.yourname.sanplan.companion`
5. Xcode автоматически создаст бесплатный профиль подписи (Free Provisioning Profile).

> Бесплатный provisioning profile Personal Team истекает через **7 дней**. Подпись приложения нужно обновлять; после истечения профиль не позволяет запускать приложение. Сохранение и срабатывание будильников после истечения подписи ещё не проверены.

### Шаг 3: Включение режима разработчика на iPhone
1. На подключенном iPhone откройте:
   **«Настройки» → «Конфиденциальность и безопасность» → «Режим разработчика» (Developer Mode)**.
2. Переведите переключатель в положение **Включено** и подтвердите перезагрузку устройства.
3. После перезагрузки разблокируйте телефон и подтвердите включение режима разработчика.

### Шаг 4: Запуск на устройстве
1. В верхней панели Xcode в списке целевых устройств выберите ваш физический iPhone (не симулятор).
2. Нажмите сочетание клавиш **Cmd + R** (или кнопку Run).
3. При первом запуске на iPhone может появиться предупреждение о ненадежном разработчике:
   - Откройте **«Настройки» → «Основные» → «VPN и управление устройством»**.
   - Найдите ваш Apple ID в списке и нажмите **«Доверять»**.
4. Запустите приложение SanPlan на iPhone.

## 4. Чек-лист проверки на реальном оборудовании (Lockscreen Test)

Для подтверждения корректной работы AlarmKit выполните следующие шаги:

1. **Разрешение доступа:**
   - При первом запуске в верхней панели приложения нажмите кнопку **«Разрешить»**.
   - В появившемся системном окне iOS разрешите SanPlan установку будильников.
2. **Тест через 1 минуту:**
   - Нажмите на меню `···` в правом верхнем углу и выберите **«Проверка через минуту»**.
   - В панели статуса отобразится сообщение: *«Тестовый будильник установлен на 1 минуту вперед»*.
3. **Блокировка экрана:**
   - Заблокируйте iPhone боковой кнопкой питания.
   - Закройте приложение или оставьте экран выключенным.
4. **Срабатывание и отключение:**
   - Ровно через 60 секунд на экране блокировки появится полноэкранный интерфейс системного будильника SanPlan со звуком и фиолетовым акцентом.
   - Нажмите кнопку **«Закрыть»** (Stop). Будильник завершит воспроизведение.
5. **Проверка 5 смещений:**
   - В веб-интерфейсе создайте задачу с несколькими напоминаниями (например, за 0, 5, 15, 30 и 60 минут).
   - В приложении нажмите **«Обновить будильники»**.
   - Убедитесь, что счетчик активных будильников увеличился на соответствующее количество.
6. **Снятие выполненных задач:**
   - Отметьте задачу выполненной в интерфейсе SanPlan.
   - Нажмите **«Обновить будильники»**.
   - Проверьте, что будильники для завершенной задачи автоматически сняты из системы.

## 6. Проверка сборки на Mac
Этот проект подготовлен на Windows: проверена структура файлов, но Swift-сборка, подпись, unit tests Xcode и звук на iPhone ещё НЕ проверены. Инструкции выше — ожидаемое поведение для проверки, а не результат аппаратного теста. Не скрывайте SanPlan и не включайте для него требование Face ID: Apple предупреждает, что такие приложения несовместимы с AlarmKit.

В папке native/ios на Mac:

```sh
xcodebuild -list -project SanPlan.xcodeproj
xcodebuild -project SanPlan.xcodeproj -scheme SanPlan -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
xcodebuild -project SanPlan.xcodeproj -scheme SanPlan -showdestinations
xcodebuild -project SanPlan.xcodeproj -scheme SanPlan -destination 'platform=iOS Simulator,name=iPhone 17' CODE_SIGNING_ALLOWED=NO test
```
В последней команде замените имя симулятора на установленное, показанное предыдущей командой. Общая схема SanPlan включает unit tests. Для аппаратной проверки используйте Run в Xcode с подключённым iPhone и своей Personal Team. Если Xcode сообщает ошибку — сохраните точный текст; успешной установки на телефоне пока никто не подтверждал.

Бесплатный provisioning Apple действует 7 дней: приложение придётся заново собрать/установить. Не покупайте подписку для этого теста. Источники: https://developer.apple.com/help/account/basics/about-your-developer-account и https://developer.apple.com/forums/thread/797158 .
