## Установка без личного Mac

1. На этом ноутбуке компоненты Apple уже установлены. На новом компьютере запустить от имени администратора iTunes64Setup.exe, затем iCloudSetup.exe из outputs/windows-installers. Не покупать тарифы iCloud.
2. Подключить разблокированный iPhone по USB, на телефоне подтвердить **«Доверять этому компьютеру»**. Проверить, что iTunes видит телефон. Для обновления по Wi-Fi включить в iTunes **«Синхронизировать с этим iPhone по Wi-Fi»**.
3. Запустить установленный AltServer.exe. При запросе Windows владелец разрешает доступ в своей частной сети. Значок появится в области уведомлений возле часов.
4. Для первой установки SanPlan зажать **Shift** и нажать значок AltServer. Выбрать **Sideload .ipa…**, подключённый iPhone и скачанный SanPlan-unsigned.ipa.
5. Ввести Apple ID и пароль **лично в AltServer**, выполнить подтверждение Apple, если потребуется. Не отправлять пароль в чат, GitHub или журналы. Подпись и установка подтверждаются только сообщением AltServer и запуском SanPlan на телефоне.
6. На iPhone: **Настройки → Основные → VPN и управление устройством**, доверить профилю своего Apple ID. Затем **Настройки → Конфиденциальность и безопасность → Режим разработчика**, включить, подтвердить перезагрузку и включение после неё.
7. Открыть SanPlan, войти в существующий аккаунт, нажать **«Разрешить»** и разрешить доступ в системном окне. После входа нажать **«Обновить будильники»**.
8. В 1.1.0 открыть **«Будильники → Диагностика AlarmKit → Проверка через 1 минуту»**, дождаться сообщения об установке и заблокировать экран. Через минуту проверить звук и системный экран будильника, затем остановить сигнал.

Для удобного обновления подписи можно установить **AltStore Classic** через AltServer: **Install AltStore → iPhone**. В AltStore: **My Apps → +**, выбрать IPA, предварительно передав его на телефон. AltStore занимает один из слотов бесплатного аккаунта. Прямая установка через Shift не требует предварительной установки AltStore, но подпись обновляется вручную.

Официальные release notes подтверждают исправление подписи для iOS 26.4. Установка SanPlan на подключённый iPhone владельца уже подтверждена USB-запросом. Версия iOS 26.6 остаётся указанной владельцем: служба метаданных не вернула её при проверке. Запуск после Developer Mode и звук AlarmKit на заблокированном экране подтверждены владельцем; проверка версии iOS через API осталась без результата.

## Проверки на физическом iPhone

Создать отдельные тестовые планы на будущее, не изменяя личные задачи. Записать время, версию iOS, смещения, счётчик и фактический звук.

| Проверка | Действие и ожидаемый результат |
| --- | --- |
| Разрешение | Запрос AlarmKit появился, доступ разрешён, тестовый сигнал устанавливается. |
| Блокировка | Тест через минуту даёт звук и системный экран после блокировки. |
| Повторная синхронизация | Дважды обновить одни планы; число будущих будильников не растёт. |
| Несколько напоминаний | План через час со смещениями [10, 0] добавляет два будущих сигнала относительно исходного счётчика. |
| Перенос времени | Перенести тестовый план, обновить; старое расписание снято, новое показано в отчёте. |
| Выполнение | Выполнить тестовую задачу, обновить; её будущие сигналы сняты. |
| Удаление | Для второй тестовой задачи удалить план, обновить; её будущие сигналы сняты. |
| Отключение | Явно отключить напоминания ([]), обновить; будущих сигналов этого плана нет. |
| Сбой сети | При будущем сигнале отключить интернет, обновить; показана ошибка, прежний сигнал остаётся и срабатывает. |
| Завершение приложения | Установить отдельный тест через минуту, завершить приложение, заблокировать; проверить звук отдельно. |
| Перезагрузка | Создать сигнал через 10 минут или позже, синхронизировать, перезагрузить, один раз разблокировать, затем заблокировать; проверить звук отдельно. |

Не скрывать SanPlan и не включать для него требование Face ID: Apple указывает на несовместимость таких приложений с AlarmKit. После тестов удалить только созданные тестовые планы и обновить будильники.

## Ограничения и повторная сборка

Это **системные будильники AlarmKit**, а не телефонные/VoIP-звонки и не обычные уведомления. Внутренний лимит 50 ближайших сигналов является политикой SanPlan. Изменения с сайта синхронизируются при открытии приложения или кнопкой обновления; постоянная фоновая синхронизация не обещается. Изменённый на другом устройстве план может звучать по старому расписанию до успешной синхронизации.

Бесплатный provisioning profile Apple истекает через **7 дней**; разрешено до 3 установленных приложений на устройстве. Обновлять подпись до истечения: повторять прямую установку того же IPA или обновлять через AltStore/AltServer. Не удалять приложение ради обычного обновления подписи. Срабатывание AlarmKit после истечения подписи не проверено; полагаться на него нельзя.

Публичный репозиторий со стандартным runner использует бесплатный GitHub Actions. Workflow запускается вручную, ограничен 20 минутами и хранит артефакт 1 день; скачанные локальные файлы сохраняются. Платные larger runners, тарифы и подписки не подключались.

Повторный запуск из Windows:

    gh workflow run iphone-build.yml --repo asanchess/sanplan-iphone --ref codex/iphone-build
    gh run list --repo asanchess/sanplan-iphone --limit 3
    gh run download RUN_ID --repo asanchess/sanplan-iphone --name SanPlan-iPhone --dir outputs/iphone-build-RUN_ID

Windows управляет сборкой; iPhone-бинарник требует macOS/Xcode и iOS SDK. Swift для Windows их не предоставляет.
