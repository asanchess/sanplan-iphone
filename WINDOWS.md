# ARNA 2.0: сборка и установка с Windows (без Mac, бесплатно)

## Как это устроено

- Приложение собирается в облаке GitHub Actions: публичный репозиторий `asanchess/sanplan-iphone`, ветка `native-rewrite`, runner `macos-26`. Для публичного репозитория это бесплатно.
- Получается неподписанный `SanPlan-unsigned.ipa`. Подписывает его AltServer на Windows вашим обычным Apple ID (Personal Team, $99 платить не нужно).
- Бесплатная подпись Apple действует **7 дней**. Продлевать её проще всего через AltStore, по Wi-Fi, пока AltServer запущен на этом ноутбуке (см. ниже). Без платного аккаунта Apple эту подпись нельзя сделать бессрочной.

## 1. Собрать IPA

```
gh workflow run iphone-build.yml --repo asanchess/sanplan-iphone --ref native-rewrite
gh run list --repo asanchess/sanplan-iphone --limit 3
gh run download RUN_ID --repo asanchess/sanplan-iphone --name SanPlan-iPhone --dir outputs/iphone-build-RUN_ID
```

Артефакт хранится 7 дней. Внутри лежат IPA, `SHA256.txt`, журналы сборки и тестов и снимки экранов.

## 2. Первая установка

Всё нужное на этом ноутбуке уже установлено: iTunes, iCloud, Apple Mobile Device Support, Bonjour и AltServer (`%LOCALAPPDATA%\SanPlanTools\AltServer\AltServer.exe`).

1. Подключите разблокированный iPhone по USB и подтвердите «Доверять этому компьютеру». В iTunes включите «Синхронизировать с этим iPhone по Wi-Fi».
2. Запустите AltServer. Его значок появится в трее возле часов.
3. Зажмите **Shift**, нажмите на значок, выберите **Sideload .ipa…**, затем свой iPhone и скачанный `SanPlan-unsigned.ipa`.
4. Введите Apple ID и пароль **сами, в окне AltServer**. Никуда больше их не отправляйте.
5. На iPhone откройте Настройки → Основные → VPN и управление устройством и доверьте профилю своего Apple ID. Режим разработчика должен быть включён: Настройки → Конфиденциальность и безопасность.
6. Откройте ARNA, войдите в аккаунт и разрешите будильники. Затем зайдите в Планы → значок будильника → «Проверка через 1 минуту», заблокируйте экран и дождитесь сигнала.

Версия 2.0 ставится поверх 1.x с тем же Apple ID: bundle id тот же, поэтому данные на телефоне сохраняются. Не удаляйте приложение перед обновлением, иначе пропадут деньги и тренировки, которые хранятся только на телефоне.

## 3. Продление подписи раз в 7 дней

**Вариант А, удобный.** Один раз поставьте AltStore Classic: AltServer → Install AltStore → iPhone. Потом в AltStore откройте My Apps → `+` и выберите IPA. Дальше AltStore сам продлевает подпись по Wi-Fi, когда телефон и ноутбук в одной сети и AltServer запущен. Можно и вручную: My Apps → Refresh All. AltStore занимает один из трёх слотов приложений бесплатного аккаунта.

**Вариант Б, вручную.** Раз в неделю повторяйте шаг 3 из раздела 2 с тем же IPA.

Если подпись истекла, приложение не откроется, но данные не пропадут. Переустановка тем же Apple ID всё восстановит. Будильники AlarmKit после истечения подписи не проверялись, поэтому продлевайте подпись заранее.

## 4. Проверка на телефоне

Эти пункты подтверждаются только на реальном iPhone, тесты на симуляторе их не заменяют.

| Проверка | Ожидаемый результат |
| --- | --- |
| Вход | Вход проходит, на «Сегодня» видны планы и сумма на день |
| Разрешение AlarmKit | Появляется системный запрос; после разрешения тестовый сигнал ставится |
| Блокировка | Тест через минуту звучит и показывает системный экран будильника |
| Приложение закрыто | Отдельный тест звучит после того, как приложение полностью закрыто |
| Отдых в тренировке | Сигнал конца отдыха звучит на заблокированном экране |
| Повторная синхронизация | После двух обновлений будильников не становится больше |
| Перенос или удаление плана | Старые сигналы снимаются |
| Голосовая запись | Запись разбирается в черновик плана |

Не скрывайте ARNA и не включайте для неё вход по Face ID: Apple пишет, что такие приложения несовместимы с AlarmKit.

## Ограничения

- Изменения, сделанные на сайте, подтягиваются при открытии приложения и при обновлении экрана. Постоянной фоновой синхронизации нет.
- Одновременно активны не больше 50 ближайших сигналов ARNA.
- Собрать iPhone-приложение без macOS/Xcode нельзя. Windows здесь только управляет облачной сборкой и подписью.
